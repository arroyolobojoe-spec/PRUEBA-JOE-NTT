High Garden Coffee - Analitica de consumo domestico de cafe (1990-2020)¶

Reto tecnico de ingenieria de ML - NTT DATA

Contexto de negocio: High Garden Coffee es una exportadora internacional de cafe. El area de innovacion quiere aprovechar una base historica de consumo domestico de cafe (1990-2020, 55 paises, distintos tipos de cafe) para identificar tendencias, informacion clave y una posible senal de precios futuros que den ventaja competitiva.

Idea central del analisis: para una exportadora, el consumo domestico en los paises productores es la otra cara del excedente exportable. A mas consumo domestico, menos cafe disponible para exportar (todo lo demas constante). Por eso el analisis recorre: tendencias, crecimiento por pais, segmentacion de paises productores, forecasting de consumo, un indice de presion de precios (simulado, con metodologia explicita) y deteccion de eventos anomalos, cerrando con recomendaciones de negocio y una propuesta bonus de chatbot con IA generativa.

1. Decisiones de preparacion de datos¶

Tipo de cafe (Coffee type): el dataset trae 4 valores: Arabica, Robusta, Arabica/Robusta, Robusta/Arabica. El orden de las etiquetas mixtas no esta documentado de forma confiable en la fuente como indicador de variedad predominante, asi que para el analisis principal (tendencias, clustering, forecasting por tipo) se agregan Arabica/Robusta y Robusta/Arabica en una sola categoria Mixto. Se conserva la columna original Coffee type sin modificar por si en el futuro se confirma que el orden si es significativo.

Unidades de consumo: el enunciado del reto dice que el consumo esta "en tazas", pero la estructura de esta serie (55 paises productores, 1990-2020, valores redondeados a miles) corresponde al formato historico de consumo domestico que publica la Organizacion Internacional del Cafe (OIC), habitualmente expresado en miles de sacos de 60 kg. No se aplica ninguna conversion sin confirmar la fuente exacta: los ejes y tablas se etiquetan de forma neutral ("unidades reportadas por la fuente") para no inducir un error de escala.

Formato: los datos vienen en formato ancho (una columna por temporada). Se transforman a formato largo (Country, Coffee type, Coffee_type_grouped, Season, Year_start, Consumption) para el analisis de series de tiempo.

3. Crecimiento y ranking de paises (CAGR)¶

Regla de calculo del CAGR (evita divisiones por cero): se valida que exista al menos un valor positivo en la serie del pais. Si 1990/91 es 0, el CAGR se calcula desde el primer anio con valor positivo registrado. Si el ultimo anio (2019/20) es 0 (el pais dejo de reportar/perdio todo su consumo domestico) o si ningun anio de la serie es positivo, el CAGR se marca como NaN y el pais se excluye del ranking de crecimiento, pero se documenta aparte como caso especial en la seccion de anomalias.

def compute_cagr(row: pd.Series):
    series = row[SEASON_COLS].astype(float)
    positive = series[series > 0]
    if positive.empty:
        return np.nan
    start_idx = positive.index[0]
    start_val = positive.iloc[0]
    end_val = series.iloc[-1]
    n_periods = SEASON_COLS.index(series.index[-1]) - SEASON_COLS.index(start_idx)
    if n_periods <= 0 or end_val <= 0:
        return np.nan
    return (end_val / start_val) ** (1 / n_periods) - 1

df_wide["CAGR"] = df_wide.apply(compute_cagr, axis=1)

def consumption_status(row: pd.Series):
    series = row[SEASON_COLS].astype(float)
    if (series > 0).sum() == 0:
        return "sin_datos"
    if series.iloc[-1] <= 0:
        return "interrumpido"
    return "activo"

4. Segmentacion de paises productores (clustering)¶

Se agrupan los 55 paises segun tres caracteristicas de su patron de consumo domestico: nivel promedio (log), crecimiento (CAGR) y volatilidad (desviacion estandar de las variaciones interanuales). Los 3 paises sin CAGR valido (sin_datos o interrumpido) se excluyen del clustering porque no tienen una senal de crecimiento comparable, y se reportan aparte. KMeans y PCA usan random_state=42 para reproducibilidad.

5. Forecasting de consumo domestico¶

Con solo 30 puntos anuales por pais, ajustar 55 modelos individuales finos arriesga sobreajuste. Se compara, mediante backtesting sobre la serie global (entrenando hasta 2014/15 y evaluando 2015/16-2019/20), un modelo de tendencia lineal contra un modelo Holt (suavizado exponencial con tendencia aditiva, sin estacionalidad por tratarse de datos anuales). El metodo con menor error (MAPE) en el backtest se usa despues para proyectar 5 anios (2020/21-2024/25) sobre: el agregado global, cada tipo de cafe agregado, y los 10 paises de mayor consumo (no se proyectan los 55 paises individualmente, para no dar una falsa sensacion de precision).

def linear_forecast(values: np.ndarray, periods: int):
    x = np.arange(len(values))
    coeffs = np.polyfit(x, values, 1)
    future_x = np.arange(len(values), len(values) + periods)
    return np.polyval(coeffs, future_x)

def holt_forecast(values: np.ndarray, periods: int):
    model = ExponentialSmoothing(values, trend="add", damped_trend=True, initialization_method="estimated")
    fit = model.fit()
    return fit.forecast(periods)

def mape(y_true, y_pred):
    y_true, y_pred = np.array(y_true), np.array(y_pred)
    mask = y_true != 0
    return np.mean(np.abs((y_true[mask] - y_pred[mask]) / y_true[mask])) * 100

global_series = global_by_year.set_index("Year_start")["Consumption"].values
train, test = global_series[:-5], global_series[-5:]

lin_pred = linear_forecast(train, 5)
holt_pred = holt_forecast(train, 5)

mape_lin = mape(test, lin_pred)
mape_holt = mape(test, holt_pred)
print(f"MAPE backtest tendencia lineal: {mape_lin:.2f}%")
print(f"MAPE backtest Holt (tendencia amortiguada): {mape_holt:.2f}%")

best_method = "linear" if mape_lin <= mape_holt else "holt"

def forecast_series(values: np.ndarray, periods: int = 5):
    if best_method == "linear":
        return linear_forecast(values, periods)
    return holt_forecast(values, periods)

6. Indice de presion de precios (SIMULADO)¶

El dataset no incluye precios de mercado. Para responder al pedido explicito del reto de "rangos de precios futuros" sin inventar datos de mercado como si fueran reales, se construye un indice ilustrativo con metodologia transparente, disenado como un oscilador de presion (no como un nivel de precio compuesto, que explotaria matematicamente si se capitaliza un crecimiento sostenido durante 30 anios):

Indice_t = 100 + k * 100 * (crecimiento_consumo_global_t - crecimiento_promedio_historico) + ruido_t

Intuicion: si el consumo domestico global crece un anio por encima de su promedio historico, una porcion mayor de la produccion se queda en el pais de origen ese anio, ajustando el excedente exportable disponible por debajo de lo habitual, lo que se traduce en el indice como una senal de mayor presion al alza sobre precios (valor por encima de 100); si crece por debajo de su promedio historico, la senal es de menor presion (valor por debajo de 100). k es una constante de sensibilidad ilustrativa (no calibrada con datos de mercado reales) y ruido_t es una perturbacion aleatoria pequena (random_state=42) que representa la variabilidad real de precios que este unico indicador no puede explicar.

Aviso explicito: este indice NO son precios reales de cafe, es una simulacion con fines demostrativos, acotada alrededor de 100 en vez de una serie que se dispara, para que su escala se pueda leer como una senal de tension relativa y no como un nivel de precio en dolares. Para una version productiva se requeriria integrar datos reales, por ejemplo el indicador compuesto de la OIC o los futuros de cafe de ICE.

def zscore(s: pd.Series):
    std = s.std()
    if std == 0 or np.isnan(std):
        return pd.Series(np.nan, index=s.index)
    return (s - s.mean()) / std

Casos estructurales relevantes que no siempre aparecen como pico puntual pero son informacion clave para negocio:

Zambia: el consumo domestico reportado cae a 0 de forma sostenida desde 2009/10 hasta 2019/20 (11 temporadas seguidas en cero), tras venir de un rango de 36.000-90.000 unidades. Es una interrupcion de reporte o de actividad, no una fluctuacion normal; se recomienda verificar con la fuente antes de usar este pais en decisiones comerciales.

Equatorial Guinea y Nepal: no tienen ningun valor positivo registrado en las 30 temporadas. Es probable que sean paises sin consumo domestico material o sin cobertura de reporte de la fuente; se excluyen de los rankings de crecimiento y del clustering por no tener senal.

Estos tres casos se marcaron automaticamente con Consumption_status en la seccion 3.

8. Conclusiones y recomendaciones de negocio¶

Consumo global: el consumo domestico global crecio de forma sostenida entre 1990/91 y 2019/20 (ver seccion 2), lo que estructuralmente reduce el excedente exportable disponible en el tiempo si la produccion no crece al mismo ritmo.

Concentracion: un grupo reducido de paises (Brasil, Indonesia, Etiopia, Mexico, Filipinas, Colombia, Venezuela, India, Vietnam, Tailandia) concentra la mayor parte del consumo domestico historico acumulado; son los mercados donde una variacion en su consumo interno tiene mayor impacto en la oferta exportable global.

Segmentacion: los clusters de la seccion 4 permiten priorizar de forma diferenciada. Los paises del segmento de mayor crecimiento absorben cada vez mas de su propia produccion (senal de alerta temprana para asegurar contratos de suministro a largo plazo antes de que su excedente exportable se reduzca mas). Los paises del segmento en declive o estable liberan (o mantienen) mas excedente exportable en el tiempo, y son candidatos a fortalecer relaciones comerciales de abastecimiento.

Forecast: la proyeccion a 2024/25 (seccion 5) da una primera estimacion cuantitativa para planear volumenes de compra/exportacion a mediano plazo, con una banda de incertidumbre explicita en vez de un numero unico.

Precios: el indice de presion de precios (seccion 6) es una prueba de concepto que conecta la dinamica de consumo con una senal de precio; para uso real en decisiones comerciales debe sustituirse o calibrarse con datos de mercado reales (ej. indicador compuesto OIC, futuros ICE), no usarse tal cual.

Calidad de datos: se recomienda a producto/datos verificar los 3 casos senalados en la seccion 7 (Zambia, Equatorial Guinea, Nepal) con la fuente original antes de tomarlos como insumo de decisiones comerciales.
